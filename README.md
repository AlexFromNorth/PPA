# Real Estate Listing App

Мини-приложение для отображения списка объектов недвижимости с возможностью переключения валюты. Использовал методологию FSD

### Технологии
- Next.js 16 
- TypeScript
- React
- Tailwind CSS

### Что улучшить
Подключить стейт-менеджер, в силу маленькости текущего проекта он здесь был избыточен. Почистить компоненты и подразбить их: чтобы лучше соблюсти KISS и DRY. Добавить тесты и реальное API. Вынести типизацию в отдельные файлы
